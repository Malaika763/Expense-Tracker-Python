# Expense Tracker

A Python-based expense management application that helps users record, manage, and analyze their daily expenses using SQLite database.

## Features

- Add new expenses
- View all expenses
- Update existing expenses
- Delete expenses
- Search expenses
- Filter expenses by date
- Generate monthly expense reports
- Set budget alerts
- Create expense charts
- Export expense data to CSV

## Technologies Used

- Python
- SQLite Database
- Matplotlib

## Project Structure

- `main.py` - Main application file
- `database.py` - Database connection and table creation
- `add_expense.py` - Add new expenses
- `view_expense.py` - Display expenses
- `update_expense.py` - Update expenses
- `delete_expense.py` - Delete expenses
- `search_expense.py` - Search expenses
- `date_filter.py` - Filter expenses by date
- `monthly_report.py` - Generate monthly reports
- `budget_alert.py` - Budget monitoring
- `expense_chart.py` - Generate charts
- `export_csv.py` - Export data
